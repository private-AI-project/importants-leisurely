# 느긋하게 — 노후 준비 글 저장소

티스토리에 올리는 글의 원본을 보관합니다. 은퇴를 앞둔 50대를 독자로 잡습니다.

## 왜 티스토리인가

새 도메인은 검색 권위가 0에서 시작합니다. 티스토리는 86입니다. 같은 글을 써도 티스토리 쪽이 먼저 올라갑니다.

그리고 이 주제의 독자가 50~60대입니다. 이 연령대는 AI 챗봇을 거의 쓰지 않고(50대 8.5%, 60대 3.4%) 검색으로 들어옵니다. 그중 다음 검색 비중이 젊은 층보다 높은데, 티스토리는 카카오 소유라 다음에서 유리합니다.

자체 도메인 블로그 세 개는 2026년 8월 말에 시작해 아직 일주일밖에 안 됐습니다. 여기에 하나를 더 붙여도 0에서 출발합니다.

## 왜 저장소를 따로 두나

티스토리는 2024년 2월에 Open API 를 없앴습니다. 글 작성·수정·이미지 첨부가 전부 막혀서 자동 발행이 불가능합니다.

그래서 **글은 여기에 마크다운으로 남기고, 발행만 손으로 합니다.** 티스토리가 저품질 판정을 내리거나 서비스를 접어도 원본은 남습니다. 나중에 자체 도메인으로 옮길 때도 그대로 씁니다.

## 쓰는 법

```bash
python3 scripts/to_tistory.py posts/2026-09-04-national-pension-age.md
```

제목·태그·요약이 화면에 뜨고 본문 HTML 이 클립보드에 들어갑니다. 티스토리 글쓰기에서 **HTML 모드로 바꾼 뒤 붙여넣습니다.**

이미지가 있으면 목록으로 알려줍니다. 이미지는 에디터에서 직접 올려야 합니다.

```bash
python3 scripts/to_tistory.py --show <글.md>    # 클립보드 대신 화면 출력
```

## 글 형식

```markdown
---
title: "제목"
date: 2026-09-04
tags: [태그1, 태그2]
description: "요약 한 줄"
---

## 소제목

본문
```

프론트매터의 네 항목이 티스토리 입력칸에 그대로 들어갑니다. 본문의 `##` 는 변환할 때 `<h3>` 이 됩니다. 글 제목은 티스토리 제목칸이 맡으므로 본문에 `#` 를 쓰지 않습니다.

## 규칙

`docs/writing-guide.md` 를 따릅니다. 특히 이 둘은 반드시 지킵니다.

- **금융 상품을 추천하지 않습니다.** 제도와 한도까지만 씁니다
- **개인의 수령액을 단정하지 않습니다.** 가입기간·소득·출생연도에 따라 다릅니다

## 나중에

티스토리에서 유입이 붙으면 자체 도메인을 만들고, 새 글은 그쪽에 쓰면서 티스토리에서 링크를 겁니다. 쌓인 권위가 새 도메인으로 흘러갑니다. 자리를 잡으면 파이프라인에 붙여 자동화합니다.
